# Автотесты на Selenium и Python

Мои решения практических заданий курса [«Автоматизация тестирования с помощью Selenium и Python»](https://stepik.org/course/575) на Stepik.

Каждый скрипт автоматизирует одну учебную страницу на [suninjuly.github.io](https://suninjuly.github.io/): находит элементы, заполняет формы, решает задачу и отправляет ответ.

## Чему я научился

- искать элементы по ID, имени, классу, тегу, тексту ссылки, CSS-селектору и XPath;
- заполнять поля, отмечать чекбоксы и радиокнопки, выбирать пункты в выпадающих списках;
- читать текст и атрибуты элементов и вычислять по ним ответ;
- выполнять JavaScript на странице, например чтобы прокрутить её до нужного элемента;
- загружать файлы через форму;
- принимать alert и переключаться между вкладками браузера;
- ждать появления нужного состояния страницы через явные ожидания (`WebDriverWait`);
- проверять результат через `assert`.

## Структура репозитория

| Файл | Что делает |

## Как запустить

1. Установите [Python 3](https://www.python.org/downloads/) и Google Chrome.
2. Установите Selenium (он сам скачает подходящий драйвер для Chrome):

   ```bash
   pip install selenium
   ```

3. Запустите любой скрипт:

   ```bash
   python lesson24.py
   ```

Откроется окно Chrome, скрипт выполнит задание, и на странице появится ответ. Большинство скриптов держат браузер открытым около 30 секунд, чтобы можно было скопировать ответ для Stepik, а затем закрывают его.
