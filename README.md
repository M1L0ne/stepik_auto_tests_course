# Автотесты на Selenium и Python

Мои решения практических заданий курса [«Автоматизация тестирования с помощью Selenium и Python»](https://stepik.org/course/575) на Stepik.

Каждый скрипт автоматизирует одну учебную страницу на [suninjuly.github.io](https://suninjuly.github.io/): находит элементы, заполняет формы, решает задачу и отправляет ответ.

## Чему я научился

- искать элементы по ID, имени, классу, тегу, тексту ссылки, CSS-селектору и XPath;
- заполнять поля, отмечать чекбоксы и радиокнопки, выбирать пункты в выпадающих списках;
- читать текст и атрибуты элементов и вычислять по ним ответ;
- выполнять JavaScript на странице, например чтобы прокрутить её до нужного элемента;
- загружать файлы через форму;
- принимать alert и переключаться между вкладками браузера;
- ждать появления нужного состояния страницы через явные ожидания (`WebDriverWait`);
- проверять результат через `assert` и `assertEqual`;
- писать тесты на unittest и PyTest, использовать фикстуры, `conftest.py` и маркировки (`skip`, `xfail`).

## Структура репозитория

Решения разложены по модулям курса. В каждой папке свой `conftest.py` (если он нужен), а папки не вложены друг в друга, чтобы настройки pytest из разных модулей не конфликтовали.

### `section1/` — первые скрипты и поиск элементов

| Файл | Что делает |

| `first_script.py` | Первый скрипт: открывает страницу, вводит ответ в поле и отправляет его |

| `lesson6_step7.py` | Заполняет большую форму, перебирая все поля через `find_elements` |
| `lesson6_step8.py` | Находит кнопку отправки по XPath |
| `lesson6_step11.py` | Тест регистрации: заполняет обязательные поля и проверяет приветствие через `assert` |

## Как запустить

1. Установите [Python 3](https://www.python.org/downloads/) и Google Chrome.
2. Установите Selenium (драйвер для Chrome он скачает сам):

   ```bash
   pip install selenium
   ```

3. Скрипты из `section1` и `section2` запускаются как обычные программы:

   ```bash
   python section2/lesson24.py
   ```

   Откроется окно Chrome, скрипт выполнит задание, и на странице появится ответ. Большинство скриптов держат браузер открытым около 30 секунд, чтобы можно было скопировать ответ для Stepik, а затем закрывают его.

4. Тесты из `section3` запускаются через PyTest:

   ```bash
   pip install pytest
   pytest -v section3
   ```

   Файл `lesson32_unittest.py` не подходит под шаблон `test_*.py`, поэтому его нужно указать явно: `pytest -v section3/lesson32_unittest.py`.
